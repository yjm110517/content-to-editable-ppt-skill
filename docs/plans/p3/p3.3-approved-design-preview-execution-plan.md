# P3.3 Approved Design Preview 执行计划

P3.3 必须在用户确认前证明每个重要视觉元素都具有明确的 P4 实现方式。Raw Generated Layer 可以表达高级视觉，但默认不得作为 P4 整页背景复用。

```text
Image Generation
→ Raw Generated Layer
→ Element Map + Reconstruction Ownership
→ Forbidden Content / Separability Audit
→ Reconstruction Compatibility Gate
→ Preview PowerPoint
→ Microsoft PowerPoint Render
→ User Approval
```

Element Map 使用 `native_shape`、`native_text`、`native_chart`、`sanitized_svg`、`reusable_raster`、`generated_background`、`generated_foreground` 和 `decorative_approximation` 分类。Native-required 元素必须有几何和 P4 Strategy；Raster 元素必须在确认前通过临时提取。

用户确认的 Final Preview 必须来自 Preview PowerPoint Render。Raster Handoff 从 Raw Layer 提取，但由 Approved Final Preview 授权。Manual Acceptance Evidence 与 Automated Replay 分离，回归不得重新生图或等待真人。

PR 顺序：Contracts → PowerPoint Preview Builder → Style Anchor → Deck Preview Workflow → Approved Preview Gate。
