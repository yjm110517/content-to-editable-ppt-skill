# Content to Editable PPT Skill 需求规格说明 v1.4

## 当前增量要求

- P2 必须表达每个正式视觉占位的语义、P1 内容来源和布局位置。
- P2 不得选择具体图库或资产。
- P3.1 v1 只使用固定版本的 Tabler Outline，并支持离线解析。
- Design Preview 和 PPT Runtime 必须使用同一 Sanitized SVG Source Hash。
- Host 不得提供任意 SVG、XML、Path 或外部图标路径。
- P3.1 不新增独立 Agent、Icon Reviewer 或模型循环。
- P3.1 完成不等于完整 P3 Visual Design 完成。
