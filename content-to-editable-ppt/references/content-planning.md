# P1 Content Planning

Use this reference when reading user materials and producing a Candidate Outline.

## Material readiness

- Treat a non-readable required material as Blocking.
- An optional non-readable material produces a Warning.
- Continue without a required material only after the user explicitly authorizes ignoring that exact failure record.
- Do not implement or assume a file-format parser; use only material the Host can read reliably.
- External research is `not_authorized` unless the user explicitly changes it.

Every fact, number, quotation and conclusion must reference a material fact or an explicit user instruction. A `derived_transition` may connect approved facts but must not introduce a new fact.

## Host budget

The initial Host planning pass produces Material Understanding and the Candidate Outline together. Do not regenerate automatically after validation failure. A new Host revision pass is allowed only for an explicit user change request, which must be hashed and recorded.
